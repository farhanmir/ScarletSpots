Deep Dive

Building a Physics-Based Lot Pressure Engine

Lot occupancy isn't a static count — it's a fluid system governed by arrival rates, dwell-time distributions, and feedback loops between adjacent lots. We model each lot as a bounded queue and apply a custom pressure function to predict saturation minutes before it happens.

Research

The "Vulture" Metric: Correcting Arrival Sampling Bias

Early crowd-sourced data was skewed — drivers who can't find spots are over-represented in the sample because they spend more time in the lot. We named this the Vulture Effect and engineered a bias-correction layer that normalizes arrival samples against dwell-weighted baselines.
