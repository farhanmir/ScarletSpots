# Website Launch Checklist

## Before shipping

- `npm run build` passes
- landing page copy matches the current native iOS app
- the App Store link in `src/App.jsx` has been replaced with the real listing
- privacy and terms pages are live and linked
- title, description, canonical URL, and OG tags are correct

## Content checks

- screenshots or mockups reflect the current SwiftUI app
- Rutgers-email-only sign-in copy is still accurate
- no outdated React Native-first wording remains
- FAQ claims still match actual product behavior and privacy posture

## Operational checks

- domain and SSL are active
- `robots.txt` and `sitemap.xml` are deployed
- support email routing works
- analytics is added only if desired and documented
