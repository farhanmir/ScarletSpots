# Website Launch Checklist

## Before shipping

- build passes with `npm run build`
- landing page copy matches the current native iOS app
- App Store download link is correct
- privacy / terms / support pages are live and linked
- metadata and canonical URL are correct

## Content checks

- screenshots/mockups reflect the current Swift app
- no outdated React Native-first wording on the landing page
- FAQ answers still match the product

## Operational checks

- domain and SSL active
- robots and sitemap deployed
- analytics added if desired
