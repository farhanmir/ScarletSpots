# ScarletSpots: Native Masterplan

This repo contains the native mobile masterplan for ScarletSpots. It targets iOS and Android via Expo, with a FastAPI + PostGIS backend.

## Highlights
- Dual-map strategy with Apple Maps on iOS and Google Maps on Android
- Knight Needle compass for close-range navigation
- Snap-to-spot flow using geofencing and motion cues
- Forecasting timeline for occupancy trends
- Two themes: Campus (default) and Knight (retro)
